Delivery autocomplete uses the existing open-source Photon search-as-you-type API, proxied by /api/address-suggest. Typing 4 or more characters fetches suggestions after a 475ms debounce. Choosing a numbered Calgary street address fills the address and updates the Leaflet map pin. Manual address entry remains available. Search terms are sent to Photon, not stored in Supabase. Five-minute in-memory result caching and a 24-request/minute per-instance client limit help respect the demo provider's fair-use limits; it has no production SLA. Replace with a contracted geocoder as volume grows.

Public OSMF Nominatim is NOT used because its terms forbid autocomplete. Photon API docs: https://github.com/komoot/photon/blob/master/docs/api-v1.md . User-visible attribution is OpenStreetMap contributors / Photon. Suggestions do not validate delivery eligibility or the precise building entrance. Unit number remains separate. Do not claim a paid order is confirmed.

QA: npm run build runs tests and Vite compile. Browser-test typing, selecting, keyboard navigation, map-pin movement, editing a previously selected address, error fallback, mobile view, and no horizontal overflow. Release through one coordinated deployment.
